Şimdi artık bilgisayarınızdan sürükle-bırak yapmak yerine, sadece bu GitHub ekranını kullanarak sitenize nasıl yeni bir HTML dosyası ekleyeceğinizi veya mevcut bir dosyayı nasıl güncelleyeceğinizi görelim:

1. Yeni Bir HTML Dosyası Nasıl Eklenir?

1. Görseldeki GitHub ekranında, yeşil <> Code butonunun hemen solunda yer alan Add file (Dosya ekle) butonuna tıklayın.
2. Açılan menüden Upload files (Dosyaları yükle) seçeneğini seçin.
3. Bilgisayarınızda hazırladığınız yeni HTML dosyasını ekrana sürükleyip bırakın.
4. Sayfanın en altındaki yeşil Commit changes butonuna basın.
(Cloudflare bu yeni dosyayı otomatik olarak fark edecek ve birkaç saniye içinde sitenize ekleyecektir.)

2. Mevcut Bir Dosya (Örn: index.html) Nasıl Düzenlenir?

1. Listeden düzenlemek istediğiniz dosyanın (örneğin index.html) üzerine tıklayın.
2. Açılan sayfanın sağ üst köşesindeki kalem (Düzenle) simgesine tıklayın.
3. Kodlarınızı tarayıcı üzerinden direkt değiştirin.
4. Sağ üstteki Commit changes... butonuna basarak kaydedin
